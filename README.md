# 🌴 Oman Farms — واحات ومزارع عُمان

موقع تفاعلي يعرض المزارع والواحات العُمانية بأسلوب عصري وتصميم ثلاثي الأبعاد.

![Oman Vision 2040](https://app.zaro.ai/api/console/workspaces/oss/read?workspace_id=ad55f015-d8c2-467f-8459-b1cc75fd599b&object_id=public-9a79ead8-f0f3-4d78-b73a-ed0c9c4dc685)

## 🚀 التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Vite** — bundler سريع
- **Tailwind CSS** — تنسيق متجاوب
- **Framer Motion** — حركات ومؤثرات بصرية
- **Lucide React** — أيقونات

## 📦 التثبيت والتشغيل

```bash
npm install
npm run dev
```

## 🏗️ البناء للإنتاج

```bash
npm run build
npm run preview
```

## 📋 الأقسام

1. **Hero Section** — عنوان رئيسي مع تأثير مغناطيسي
2. **Marquee Section** — صور متحركة للمزارع والواحات
3. **About Section** — عن المبادرة مع صور القادة
4. **Services Section** — الخدمات الزراعية
5. **Projects Section** — المشاريع بتأثير تكديس البطاقات
